FAQ

Fair questions.

Can I use Nest Music without a YouTube Music subscription?

Yes. Browsing, search and playback work without one; a few features require an active subscription. Free users can still browse and search everything.

Is this legal?

Yes. Nest Music is a third-party client that connects to YouTube Music's official API — similar to how web browsers connect to it.

What's the difference between FOSS and GMS builds?

FOSS contains no Google libraries and supports music recognition via Shazam; GMS includes Google Play Services for enhanced features like Cast.

Do I need to log in?

Only if you want your library and playlists: a Google account syncs your likes, playlists and subscriptions.

Can I download songs for offline playback?

Yes — songs, albums and playlists can be cached or downloaded for offline use, space permitting.

What if YouTube Music is blocked in my country?

Nest Music needs YouTube Music to be reachable: a VPN or proxy to a supported region makes everything work normally.
