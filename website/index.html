A few more notes

Before you press play.

A little context for your first listen.

What is Nest Music?

Nest Music is an open-source, unofficial YouTube Music client with Android and desktop apps. It is an independent project, not a Google or YouTube product.

Do all platforms have the same features?

Not necessarily. Android and desktop are separate clients with different integrations. Check the README for platform-specific features, prerequisites and setup instructions.

Does it work without an internet connection?

Streaming and discovery need an internet connection. Supported downloads and cached music can be played offline once saved on your device.

Are there account or regional requirements?

Account-based library and playlist features require a Google account. Some features may require a YouTube Music subscription. YouTube Music availability also varies by region; review the project README before installing.

How can I help the project?

Report reproducible bugs, improve documentation or contribute fixes. Read the contribution guide before opening a pull request.
